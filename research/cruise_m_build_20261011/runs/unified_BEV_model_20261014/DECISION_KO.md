# 최종 목표: 하나의 공통 Bolt BEV 모델 → 가상 EREV

2026-10-14 사용자 정정 반영. C2를 최종 모델로 영구 동결하지 않는다. C2 온난 검증 결과는 과거 버전의 성과·회귀 비교 기준으로 보존한다. 기존 안내의 “C2 성능4회부터 실행” 우선순위는 보류하고, 기존 자료로 공통 배터리·제어 경계 개선을 우선한다.

## 모델과 버전의 구분

최종 연구용 기준은 하나의 공통 차량/구동계/배터리/BMS 모델이다. C1/C2/개선 후보는 개발 이력이며 최종 논문에 서로 다른 구간별 모델을 골라 넣는 용도가 아니다. SOC·온도에 따라 OCV/저항/출력한계가 변하는 하나의 맵은 하나의 모델이다. 시험마다 용량·손실보정·SOC 편차를 임의로 바꾸는 방식은 배제한다. 초기 SOC/온도/주행 입력은 각 시험의 초기조건으로 설정하되 동일한 초기화 규칙을 쓴다.

“하나의 최적 모델”은 확보한 자료와 목표 운전영역을 함께 설명하는 일관된 모델을 의미한다. 제한된 자료에서 물리적 매개변수가 유일하게 식별되거나 모든 운전영역이 완벽하게 재현된다는 의미는 아니다. 최종 후보 검증 결과를 보고 주장 범위를 정한다. 전체 모델을 변경했다면 기존 시험도 새 공통 모델로 다시 평가하고, 옛 C2 통과를 새 후보의 통과로 옮겨 쓰지 않는다.

모델을 고정하는 시점은 최종 후보의 보정·검증을 마친 후 EREV 제어전략들을 비교할 때이다. 같은 하드웨어 조건의 S0–S4에는 같은 배터리와 구동계를 사용한다. 배터리 병렬수·발전기 용량 변경은 연구의 설계축으로 명시하며 공통 셀 모델에서 일관되게 환산한다. 전략마다 배터리 모델을 재보정하지 않는다.

## 이번에 실제 수행한 공통 배터리 계산

개발 적합 자료는060/061/066/064이다. 058/059/067은 파라미터 적합 잔차에는 넣지 않았지만 이전에 결과를 검토했고 개발 후보 선택에도 영향을 주므로 새 독립 검증이라고 부르지 않는다. 첫 MSE 전용 후보는059 평균편차1.029V로 기준을 넘었다. 첫 결과를 보존한 뒤 모든 적합 시험의 평균편차를 줄이는 항을 공통 목적함수에 추가했다. 기준 자체는 전압RMSE2V/평균편차1V를 유지했다. 재검토 자료를 본 후의 개발 단계이며 신규 blind validation 주장은 없다.

모든 시험에서 시작5초 중 |I|<3A의 전압·전류 중앙값으로 초기 SOC를 역산했다. 공통 유효 용량·단조 OCV 곡선·공통 R 배율로 전체 전류를 적분했다. 전압200–450V/전류1000A 점검, 2초 초과 간격의 중단 규칙을 유지했다. 064/067의 접촉기·계측 말단을 평형 OCV로 해석하지 않는다. 저SOC 곡선은 부하 중 유효 재현 곡선이며 정지 평형 OCV/저항/RC의 물리 식별 결과가 아니다.

개발 후보의 공통 유효 팩 용량은169.356846Ah(셀56.452282Ah), 원본 대비 R 배율1.033733이다. OCV100%는400.766V, OCV0%는281.933V이며 OCV 적분×모델용량은59.766kWh이다. 이는 입력곡선의 적분값이며 실측 가용 에너지나 인증 에너지로 승격하지 않는다. 이 후보는 아직 최종 모델로 채택하지 않았다.

## 제어 연결 재검토에서 확인한 보완 대상

저SOC 출력한계는 단순히 배터리 표만 바꾸어 해결할 수 없다. 기존 SOC20%에서0kW로 되는 방전제한은 실차 식별값이 아니므로 최종 모델에 그대로 확정하지 않는다. 또한 직렬2모듈의 SOC 좌표와 제한/전류 변환 경계를 함께 정리한다.

저장본의 HV Battery 서브시스템에서 State of charge.4는Module1, State of charge.5는Module2에 연결된다. 그러나 상위 BMS ECM의 SoC Module2 입력은State of charge.4에 연결돼 있다. 또한 Power Module2 입력은Module2의 Power.5가 아니라Power loss로 연결된다. 두 모듈의 SOC가 동일한 온난 시험에서는 SOC 중복의 영향이 숨을 수 있지만 최종 모델에서 의도대로 정리해야 한다. 단자전압×단자전류로 별도 계산한 기존 실측 비교 결과를 이 발견만으로 취소하지 않는다. BMS 계산 신호·제어 영향은 따로 확인한다.

ANL064 채널도 확인했다. HVBatt_pack_capacity_HPCM2는1850인데 단위가kW로 선언돼 있어 물리 용량값으로 복사할 수 없다. 최소 SOC limit 채널은1.176, 팩 최소전압 채널은약241.28–276.64V, 최대전압 채널은약387.4–401.96V였다. 이는 관측 채널/범위이며 실제 BMS 차단조건의 완전 식별로 취급하지 않는다. 이 자료에 가용 구동 방전전력/전류한계가 검증된 형태로 제공됐다고 주장하지 않는다.

## 앞으로의 작업 순서

1. 공통 배터리 후보의 차수·곡선·용량·초기화 규칙을 정리하고 식별 불확실성을 명시한다. 온난 주행·장시간 방전을 동시에 설명하는 목적을 유지한다.
2. BMS 모듈 신호 연결과 SOC/전압/전류/출력 경계를 보완한다. 실차 근거가 없는 보호정책은 명시적인 가정·민감도 대상으로 둔다. 공식 성능 수치만 맞추는 임의 제한 변경은 하지 않는다.
3. 같은 개선 후보로 기존 주행/장시간 방전과 공식 가속·주행거리의 필요한 CRUISE 확인 실행을 한 번의 명확한 목록으로 준비한다. 지금은 기존 C2 성능4회를 요구하지 않는다.
4. 검증 후 하나의 기준 모델을 선정하고 가상 EREV 발전계·기동 제어를 추가한다. 동일 하드웨어/운전조건에서 제어전략 비교를 시작할 때 plant parameter를 고정한다.

자료·계산은screen_unified_battery.py, screen_unified_battery_power.py, development_screen.json, fixed_power_screen.json에 저장했다. C2 입력·프로젝트와 실제 검증 결과는 수정하지 않았다. 새 .proj, 실제 solver, 공식 성능 비교는 미완료이다.
