# BEV 검증 종료 계약 — 공통 차량 모델

## 완료라고 부를 범위

동일 Bolt 시험차량의 온난 조건에서, **하나의 OCV/R/용량·EDU·회생·충방전 제한**으로 지정된 주행/방전 자료의 속도·거리·DC 에너지·전압을 사전 기준 내 재현한다. 시험별로 물리 파라미터를 바꾸지 않는다. 초기SOC는 동일한 초기 V/I 역산 규칙, 주행 프로파일·시험 온도·기간은 각 시험의 실제 조건을 사용한다.

OEM BMS 전체, 저온·셀 편차, 저SOC 최대 펄스출력, 실제 Bolt EREV 성능 또는 유일한 최적 물리 파라미터의 검증까지 확대하지 않는다. 차량 수준 유효 모델을 검증한다. 하나의 공통 모델과 파라미터 식별의 유일성은 다른 주장이다.

## 종료 판단에 사용할 자료 묶음

| 자료 | 역할 | 현재 상태 |
|---|---|---|
| 060 | 중간SOC 주행 및 C3 구현 확인 | R2 실제 7기준 통과. 제한 변경 후 기존 출력에서 제어 여유 대조 필요 |
| 058 | 높은SOC 회생·주행 확인 | 공통 제한 후보 실제 7기준 통과 |
| 059 | 다른 온난 주행의 전압 평균편차·에너지 회귀 | C2 실제 통과, C3는 사전 계산만 있어 최종 공통 모델 확인 대상 |
| 066 | 긴 주행·높은 부하·회생 회귀 | C2 실제 통과, C3는 사전 계산만 있어 최종 공통 모델 확인 대상 |
| 067 | 낮은SOC까지 장시간 방전 | 실행 실패. 실패 직전 자료 분석 우선 |

061·064는 개발/보조 근거로 유지하며 새로운 필수 확인 실행으로 추가하지 않는다. 다른 주행/새 조건은 위 묶음에 명확한 결함을 발견할 때만 이유와 함께 추가한다. 067 실패자료 분석 후 공통 수정의 범위를 정하고 필요한 회귀 실행을 **하나의 최종 묶음**으로 준비한다. 전체 모델 변경이면 이미 통과한 시험도 영향 범위에 따라 그 묶음에 포함해야 한다. 이미 통과한 과거 버전의 결과를 새 버전 실행처럼 합치지 않는다.

## 판정 기준

에너지±5%, 전압 RMSE≤2 V·평균편차±1 V, 속도 RMSE≤1 km/h, 거리±0.5%, 적분 DC 수지≤1%, 발전기OFF. 원래 기준을 유지하고 결과에 맞춰 완화하지 않는다. 지정된 유효 측정 주행 기간을 완료하고 SOC/전압 계산이 정의역 안에 있어야 한다. 067의 예정기간 실패는 현 단계 미완료로 기록한다.

에너지 부족과 종료 처리 오류를 분리한다. 정상적인 소진 종료 로직을 구현하는 것만으로 실측 재현 문제가 해결되는 것은 아니다. 모델SOC0%와 실차 종료 시점의 일치를 정밀하게 주장하려면 유효 SOC 좌표·최종 전압·접촉기 사건의 식별이 추가로 필요하다. 이 주장을 BEV 기본 검증 완료의 정의에 몰래 포함하거나 실패 후 기준으로 추가하지 않는다.

## 이후 업무와 구분

공식 가속·인증 주행거리 비교는 이전에 요청된 후속 성능 비교로 계속 준비하되, 시험법·보정·종료 조건의 차이를 구분한다. 저SOC 최대출력·발전기 기동 지연은 가상 EREV 연구의 가정/민감도로 별도 평가한다. BEV 기초 재현을 마친 뒤 이 단계로 넘어간다. 모델 적용범위·남은 가정을 중간보고에 명시하고 근거 없이 '완전 검증'으로 쓰지 않는다.
