# 공통 제한 후보 확인 — 058 → 067

060 C3 R2 실제 실행은 기존 7개 기준을 통과했다. 이번 파일은 같은 OCV·저항·용량에 공통 충방전 제한을 적용한 다음 개발 후보이며, 아직 CRUISE M에서 실행하지 않았다.

## 실행 순서

1. ZIP을 폴더에 모두 풀고 `C3_LIMITS_ANL61905058.proj`를 연다.
2. 모델 `REEV_MBE`, Case `Cycle Run → ANL61905060`을 선택한다. **Case 표시 이름은 두 파일 모두 기존 ANL61905060이다.** 이전 Case 연결 오류를 예방하기 위해 이름과 슬롯 구조를 유지했다. 실제 내장 프로파일은 파일 이름에 해당하는 시험으로 교체했다.
3. 058은 종료시간 **1489.898579 s**, 초기 모델 SOC **98.775990%**, 배터리 온도 **24°C**인지 확인하고 실행한다. 별도 DAT를 가져올 필요가 없다.
4. 결과를 `battery_058.csv`, `velocity_058.csv`, `generator_058.csv`로 내보낸다. 배터리 Voltage/Current/SoC, 속도 Desired/Actual Velocity·E-Motor Current·E-Consumer Current, 발전기 기존 7개 신호를 모두 포함한다. 기존 060 내보내기 항목과 동일하다. 저장한 실행 프로젝트와 solver log도 보관한다.
5. 이어 `C3_LIMITS_ANL61905067.proj`를 연다. 같은 모델·Case를 선택하고, 종료시간 **10122.190356 s**, 초기 모델 SOC **81.753591%**, 배터리 온도 **24.5°C**를 확인한다.
6. 동일하게 `battery_067.csv`, `velocity_067.csv`, `generator_067.csv`를 내보낸다. 첫 실행이 실패하면 오류 원문·solver log를 보내고 두 번째 실행은 보류한다.

## 이번에 확인하는 것

- 058: 높은 SOC에서 배터리 충전 여유에 맞춘 회생 제한이 에너지·전압 비교에 미치는 영향.
- 067: 기존 진단용 SOC20% 방전 차단을 제거한 공통 모델이 장시간 방전의 전압·에너지·속도 기록을 재현하는지.
- 067은 측정 속도 추종 시험이다. 저SOC 최대출력, 추월성능 또는 인증 주행거리 시험이 아니다. 마지막 주행 후 10초까지만 사용하여 정차 뒤 접촉기 차단/계측 전압 붕괴를 제외했다.

## 공통 변경과 가정

- OCV·저항·169.356846 Ah 용량, EDU·차량 파라미터, 10–20 km/h 회생 속도 가중치는 유지했다. 발전기는 SOC와 관계없이 OFF이다.
- SOC20% 진단용 방전 차단 및 350 V 전류 계산 분모 하한을 대체했다. 350 V는 실차 BMS 차단 전압이 아니었다.
- 공통 제한표는 OCV·저항과 **242.32–402 V, 방전530 A, 충전160 A**로 계산했다. 전류 한계는 실차 OEM 값이 아니라 모델 가정이다. 자세한 근거와 한계는 `POLICY_KO.md`에 있다.
- 기존 **40 kW 배터리 회생 전력** 상한은 차량 제어 조건으로 유지했다. 배터리 자체 충전 수용력과 분리했다.
- 이 두 실행을 통과해도 저온·고부하 BMS가 검증되지는 않는다. 공통 모델 채택 전에는 다른 기존 시험의 회귀 확인과 공식 가속·주행거리 시험이 남는다.

## 결과 분석

CSV별 첫 줄 신호명, 둘째 줄 단위, 그 다음부터 숫자 형식을 유지한다. 분석 예:

`python evaluate_C3_common_limits.py --package . --test 61905058 --exports ./exports_058`

기존 연구 기준: 에너지 오차 ±5%, 전압 RMSE 2 V 이하·편향 ±1 V, 속도 RMSE 1 km/h 이하, 거리 오차 ±0.5%, DC 수지 오차 1% 이하, 발전기 OFF. 보정에 이미 사용하거나 열람한 동일 차량 자료이므로 독립 검증으로 부르지 않는다.
