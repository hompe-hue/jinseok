# C1 실제 보정 확인 통과 — 다음은 066 독립 검증 1회

2026-10-14. 사용자가 C1 CAL060/CAL061에서 내보낸 실제 CSV 6개를 ANL 원시 실측과 비교했다. 사전 고정 궤적 계산을 실행 결과로 대신하지 않았다. 두 시험이 기존에 고정한 연구용 평가 기준을 모두 만족했으므로 C1 수치를 유지하고 066 독립 검증으로 진행한다. 060/061은 보정에 사용한 시험이므로 독립 검증 완료라고 부르지 않는다.

## C1이 실제로 적용됐는지 확인

- 실제 SOC·전류에 C1 OCV/R를 적용한 전압은 출력과 RMSE0.00100/0.00093V, 최대0.00364/0.00300V 차이다. 현재 관측 범위에서 정적 배터리 계산의 적용을 확인했다.
- 실제 모터 토크·속도로 C1 Q1/Q4 및 저토크 연결 보간을 재생한 손실은 최대2.04e−14/1.62e−14kW 차이로 출력과 대응했다. 각각2919/1338개의 활성 표본과 회생 저토크 연결300/94개 표본을 확인했다.
- 따라서 오래된 CSV를 새 C1 결과로 오인한 것이 아니며, 새 표의 실제 적용이 관측 출력에서 확인된다. 별도의 실행 프로젝트 해시가 포함된 solver log를 받은 것은 아니다. 이 점검은 개별 성분의 물리적 독립 검증이 아니다.

## 남는 잔차와 범위

061 전압 평균편차 +0.9722V는 1V 기준에 가깝다. 두 시험의 최대 순간 전압 편차는5.11/6.03V이고, 전체 RMSE 통과를 모든 순간의 오차 제한 통과로 바꾸어 쓰지 않는다. 최대 편차는 각각3134/1208초에서 발생했다.

총 방전 에너지 오차는 +1.23/+1.03%, 총 회수 에너지 오차는 +4.35/+8.31%다. 순에너지 목표는 만족하지만 회수 에너지 잔차가 남으며, 회생 분배를 완전히 식별했다고 주장하지 않는다. 이 잔차와 기존에 선언한 지표를 함께 보고하고, 이번 결과를 이유로 새로운 입력 보정을 추가하지 않는다.

C1은 따뜻한 조건의 차량 수준 유효 모델이며, 셀 평형 OCV/R·neutral 기계손실·저SOC/저온 가용출력의 물리적 식별 완료가 아니다. EREV 연구의 미검증 출력·발전 동특성은 별도 범위로 유지한다.

## 고정과 다음 사용자 작업
