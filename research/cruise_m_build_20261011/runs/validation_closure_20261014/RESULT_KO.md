# Bolt BEV 실측 비교 완료까지 남은 작업과066 평가 준비

작성일2026-10-14 KST. 연구방향 검토에서 BEV 실측 비교 작업으로 복귀했다. 현재 모델 신뢰성 검증은 미완료이며 이번 작업에서 CRUISE M을 실행하거나 물리 입력을 보정하지 않았다.

## 현재 판단

남은 큰 단계는 세 가지다.060/061의 구동 에너지·전압 잔차 보정 근거와 입력 동결,066 독립 연속 실행 및 비교,검증 결과의 중간보고 반영이다. 기본 입력·단위·맵 적용·파일 구현 점검은 완료했지만 핵심 보정이 남아 있으므로 임의 진행률 퍼센트로 거의 완료됐다고 표현하지 않는다.

보정안이 한 차례에 통과한다면 사용자 실행은 보정안060/061 확인2회와066 연속 평가1회의 최소3회다. 아직 보정안을 확정하지 않았으므로3회만으로 완료한다고 보장하지 않는다. 같은 설정의 기존060/061을 반복 실행하는 요청은 하지 않는다.066 내부7개 구간은7회의 별도 초기화 실행이 아니라1회의 연속 실행에서 평가한다.

중간보고까지는10월14일 기준16일이다.10/21 보정 입력 동결,10/25 독립 평가,10/26~29 보고 갱신을 작업 목표로 유지한다. 첫 보정 결과와 현재 프로젝트 확보에 의존하며 완료일 예측이나 실행 실적이 아니다.

**양의 모터 출력 구간에 주요 오차가 반복된다.** 음의 출력과 저출력 이동 구간의 signed 잔차를0으로 치환하는 고정궤적 회계 시나리오에서도060 약+8.85%,061 약+9.04%가 남는다. 분류 문턱0.5/1/2kW의 결과는060 +8.74~8.90%,061 +8.79~9.11%다. 실제 회생제어를 바꾼 후의 예측값이 아니며, 회생만으로 현재 전체오차가 없어지는 근거가 부족하다는 진단이다.

060이+5% 상한으로 들어가려면 현재 소비에서 최소0.462451kWh,061은 약0.119183kWh가 줄어야 한다. 회생 분배 고정은 유지하되 주 작업은 구동 손실 경계와 배터리 전압 잔차의 근거다. 전역 EDU이득·OCV/R·SOC편향을 동시에 맞춘 기존 로컬 후보는 실제 CRUISE 비교·독립 검증을 거치지 않았으므로 최종 입력으로 적용하지 않는다.

## 독립 검증 실행 전후의 완료 조건

1. 현재 .proj의 입력과060/061 결과를 연결하고 변경 항목을 기록한다. 회생 분배와 구동 손실 경계를 분리한다.
2. 근거 있는 보정 후보에서060/061을 한 묶음으로 확인한다. 여러 항목 변경 시 각 근거·식별 범위와 효과를 기록한다. 입력 hash와초기화 규칙을 동결한다.
3. 동결한 입력으로066을 한 번 연속 실행한다. 발전기·엔진·연료OFF, 프로파일·온도·보조부하와 BMS 설정을 보존한다.066 결과로 보정하면 그 시험은 더 이상 미사용 최종검증이 아니다.
4. velocity_ANL61905066.csv, battery_ANL61905066.csv, generator_ANL61905066.csv와 같은 실행의 .proj·solver log를 받는다. 준비된 scripts/verify_066_exports.py로 원시단자DC·전압·전류·추종·거리·수지 및 구간별 지표를 계산한다.
5. 목표 미충족이면 원인과 적용범위를 보고한다. 해당시험의조건부재현과독립일반화의성공을구분한다. 실제BMS맵·저SOC최적값·발전계전체 검증으로 확대하지 않는다.

현재 준비물은 입력/평가 준비 완료 상태다. 최종보정 프로젝트, Windows CRUISE M import/solver 시험,066 비교성공은 미완료다. Python코드 문법검사와 source/DAT 숫자검사만으로 실제 실행을 완료 처리하지 않는다.
