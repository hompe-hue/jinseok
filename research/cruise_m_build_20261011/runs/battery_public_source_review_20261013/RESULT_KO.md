# 공개 배터리 자료의 적용 가능성 검토

검토일: 2026-10-13. 공개 일차 출처의 원문 3건을 다운로드하고 PDF 주요 페이지를 렌더링해 확인했다. 원문은 sources 폴더, URL·크기·SHA256은 download_manifest.json에 있다.

INL 매뉴얼의 휴지는 단순히 짧은 정지를 의미하지 않는다. 정의에서 최소 1시간 또는 열·전압 평형에 필요한 시간과 안정화 조건을 제시한다(단위/기준은 원문 적용 수준 확인 필요). 이번 18~20초 정지는 이 조건과 다르다. HPPC에서 다양한 SOC의 방전·회생 펄스와 휴지 전압을 확보하는 절차가 필요하다.

추가 검색에서 2022년 Bolt 64 kWh 독립 팩의 공개 관측 데이터도 발견했으나 2017년 실측 팩과 연식·팩 세대·운전 맥락·표본 간격이 달라 직접 호환 자료로 채택하지 않았다. LG MJ1 18650 전극 GITT도 셀 형상/시험 대상이 달라 대체하지 않았다. 발견한 URL은 검색 로그에 보존했다. 이 검토는 전체 인터넷에 자료가 없다는 증명이 아니며, **검토한 출처에서 현재 입력을 교체할 호환 수치/원시 펄스 데이터를 확보하지 못했다**는 판정이다.

## 완료·다음 시작점

공개 출처 확인·원문 다운로드·시각 검증을 완료했다. 확인된 그림·방법론·설계 용량만으로 OCV/R/RC를 수정할 근거는 확보되지 않았다. 다음은 문헌 용량 두 값의 의미를 유지한 오프라인 민감도 비교(초기 SOC/맵 고정)를 수행하여 용량만의 영향 방향과 크기를 확인하고, 배터리 보완에 남은 자료 요구조건을 확정하는 것이다. 현재 CRUISE M 추가 실행 요청은 없다.
