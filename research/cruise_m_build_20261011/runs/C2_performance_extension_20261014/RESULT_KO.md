# C2 성능 비교 준비와 적용 범위 재검토 — 2026-10-14

## 결정

C2 온난 조건의 보정 및 미사용 시험 평가는 보존한다. 반복적인 온난 보정을 중단하는 판단에는 동의한다. 다만 이를 저SOC·지속 고부하까지 검증한 실차 대표 모델로 승격하지 않는다. 공식 가속과 EPA 표기 주행거리와의 비교 실행은 별도 성능 점검으로 진행한다. 결과를 공식값에 맞추기 위해 C2 입력을 변경하지 않는다.

사용자 의견 중 “독립 검증 표현이 강하다”는 지적은 타당하다. 보정 자료와 분리했다는 의미의 hold-out 평가는 성립한다. 그러나 차량·시험기관·시험 계열까지 독립인 검증이라는 의미는 성립하지 않는다. 058/059는 동일 VIN 및 시험 캠페인의 미사용 시험이다.

**수정할 주장:** “온난 조건(약24–24.5°C), 모델 SOC 약79.5–94.2%에서 보정에 쓰지 않은 동일 차량 시험2건이 사전에 고정한 연구용 기준을 통과했다.” 60% 부근은 보정 자료의 범위이다. SOC는 모델 좌표이고 CAN SOC와 같다고 식별되지 않았다. 066은 C2 보정 자료이며 독립 검증으로 다시 분류하지 않는다.

## 동결 C2로 새로 확인한 ANL 방전 시험

공개 원본 TDMS 61905064/067을 다시 확보했다. 064 원본 TDMS의 SHA256는5680c75633dfcab2403269a3e313316f7d8c116a7c7fb845cd3a204a6098c11b이다. 과거793593... 해시는 선택된 원본 행 CSV의 해시이며 같은 파일의 해시가 아니다. 067 원본은 기존 fd0f662... 해시와 일치한다. 출처·바이트·해시는sources/source_manifest.json에 기록했다.

이번 계산은 CRUISE M 차량 실행이 아닌 **실측 전류 입력 배터리 재현**이다. C2의 161.2413Ah, 25°C 정적 OCV/R 입력을 동결했다. 시작5초 중 |전류|<3A의 전압·전류 중앙값으로 초기 모델 SOC를 역산하고, 계측 고유 시각에서 전류를 사다리꼴 적분했다. CAN은 별도 시각에 대해 최대2초 이전값 유지로 정렬했다. 전압200–450V 밖 자료, 2초 초과 계측 간격을 가로질러 전하를 적분하지 않고 첫 불량 계측 간격 이후는 평가에서 제외했다. 평가에는 시작20초 이후, 모델 SOC0–100%에 있는 자료만 썼다. 모델 SOC를0으로 클리핑하여 음수 상태를 숨기지 않았다.

전압 기준2V/평균1V를 이 확장 재현에 진단적으로 적용하면 둘 다 미달이다. 이는 기존 온난 holdout 통과를 취소하는 결과가 아니라, **C2를 장시간 방전 전체 영역에 확장할 수 없다는 새 증거**이다. 특히 모델 SOC20%에서 방전제한표의 출력은0kW인데 실측 배터리는 약17kW를 계속 공급한다. SOC 좌표를 CAN과 같게 보지 않아도, 같은 경과시간에 추적한 동결 C2의 상태와 실측 부하가 불일치한다. 제어 연결에서 이 표가 실제 어떤 한계로 적용되는지는 새로운 CRUISE 실행의 전류·가용출력·속도 출력으로 확인한다.

관측 원인을 “셀 실제 용량이 반드시 XAh이다”로 단정하지 않는다. 초기 OCV 역산, 유효 용량, 정적 OCV/R의 온도·이력 생략과 모델 SOC 좌표가 함께 영향을 준다. 064/067의 실제 온도는 약24–31°C이며 C2는 온도 의존성을 식별하지 않았다. 누적전하가 모델 상태범위를 벗어난 구간은 평가 표에서 제외했고, 이를 추가 PASS 자료로 취급하지 않는다.

## “공개 ANL만으로 둘 다 보완”에 대한 의견

표현 수정은 지금 완료할 수 있다. 배터리의 부하 중 전압·방전 지속성도 이 자료로 평가·보완할 수 있다. 그러나 두 시험의 저 CAN SOC 방전출력95백분위는 약17.3kW이고, 고출력 펄스 시험이 아니다. 앞선 조사에서300초 이상 정지 저전류 휴지구간은0개였으며 충분한 평형 OCV/반복 HPPC 근거가 없다. 따라서 **저SOC에서150kW 가속을 얼마나 공급하는지, 전류한계·BMS 차단정책이 무엇인지는 이 시험만으로 검증할 수 없다.**

현실적인 후속은 C2를 중간보고의 범위가 제한된 차량 수준 기준으로 유지하고, 별도 배터리 확장 후보를 구성하는 것이다. 064를 부하 중 유효 배터리 보완에 사용할 경우067은 보정에서 제외하되 동일 캠페인 반복 평가라고 명시한다. OCV/R/용량을 동시에 물리 식별했다고 주장하지 않는다. 저SOC 가용출력·저온·발전기 지연은 확보되는 자료 범위 밖에서 민감도/불확실성 축으로 둔다. EREV 구조·제어군·유한 미션 경계 분석의 준비는 병행할 수 있지만, 단일 C2의 저SOC 성능을 실차 사실로 논문 결론에 사용하지 않는다.

## 공식 성능 비교와 남은 실제 실행

GM2017 기술 문서의 가속은0–60mph(96.56064km/h) 약6.5초(GM 시험)이다. 0–100km/h와 혼용하지 않는다. C2 시험질량1757.6704kg를 유지하며, GM 문서 공차1619kg와 시험질량 차이를 명시한다. GM의 운전자·SOC·타이어·기상·rollout 조건이 모두 공개된 것은 아니므로 엄격한6.5초 PASS 판정을 새로 만들지 않는다.

EPA2017 표기는복합238mi(383.0287km), 도심255mi, 고속217mi이다. EPA 원본 UDDS/HWFET 각각을 새로 SOC100%에서 반복한다. 배터리의 전 구간과 SOC100%는 현재 검증범위 밖이다. 연구용 SOC20 한계 또는 지속 속도부족으로 제한된 거리를 계산하고, 보정계수0.7의 예시와0.55/0.45 합산은 조건부 비교로만 표시한다. 해당2017Bolt가 실제 사용한 인증 절차·조정계수·가용 에너지창을 확인하지 않은 상태에서 인증 주행거리 재현으로 쓰지 않는다. 벽전원 기준28kWh/100mi에는 충전 손실이 포함되므로 팩 DC소비와 직접 동일시하지 않는다.

**실제 실행 결과는 아직 없다.** 제공한4개 프로젝트는 C2의 손실맵·OCV/R·유효용량·방전제한표를 보존한 시험 사본이며 ZIP CRC·XML 및 변경 범위만 검증했다. CRUISE M 열기·Data Checks·솔버 실행은 사용자의 Windows 환경에서 확인해야 한다. 상세 순서는START_HERE_KO.md에 있다.
