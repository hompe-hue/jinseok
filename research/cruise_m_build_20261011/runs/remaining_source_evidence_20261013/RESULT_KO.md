# 남은 오차 근거 확인: 시험조건 대응 확정, 손실 경계는 추가 분리 필요

2026-10-13. 원본 61905060/61 TDMS의 메타데이터·시계열과 공개 일차 출처를 대조했다. 입력 변경·실측에 대한 계수 적합·추가 CRUISE M 실행은 하지 않았다. 자료 품질/계산 감사는 완료했으며, 물리 파라미터 보완의 근거가 모두 확보됐다는 뜻은 아니다.

## 1. 실제 시험의 질량과 Target ABC가 현재 모델과 일치한다

두 원본 모두 Front/Road Load, 시험중량 3875lb, Target ABC 28.4/0.2018/0.01948, Set ABC 9.7782/0.16285/0.017992를 기록한다. 원본 SHA256은 기존 보존 해시와 일치한다. 요약 PDF만 보았을 때 남았던 질량/ABC 대응의 불확실성을 원본 기록으로 해소했다.

ABC의 문자열 자체에 단위 속성은 없다. 미국 road-load 관례인 lbf 및 mph를 사용한 환산이며, 기존 입력 변환과 EPA 문서의 ABC 단위에 대응한다. 이 점검은 기록된 시험 설정의 대응 확인이고 실제 coastdown 계측 정확성이나 실행 중 Dyno 부하 정확성을 인증하지 않는다. Gross weight를 질량에 중복 합산하지 않는다. 현재 질량/Target ABC 숫자를 오차에 맞춰 바꿀 근거는 없다.

## 2. Set ABC를 그대로 모델에 넣을 수 없다

| Target ABC 저항 일 | 9.297670 kWh | 2.836471 kWh |
| Set ABC 저항 일 | 7.139419 kWh | 2.078126 kWh |

| Front tractive force×speed 채널 적분 후보 | 7.051532 kWh | 2.071104 kWh |

Target−Set은 Dyno에 탑재된 차량의 손실을 보정하는 부하 설정 차이다. 그 전체가 EDU 기어 손실이라는 뜻은 아니며 타이어/베어링/브레이크/회전저항 등 경계를 분리해야 한다. 위 전력 채널은 계측 위치/제어 의미의 한계가 있어 독립적인 모터 축출력으로 바꾸어 인용하지 않는다. LoadCell×speed는 음의 순적분을 보였으므로 tractive force와 같은 양의 구동력으로 혼용하면 안 된다. Rear dyno 속도는 두 파일 모두 0mph다.

## 3. 새로 찾은 우선 원인 후보: Target ABC와 EDU 내장 회전손실의 경계 겹침

EPA SAE 2017-01-0899의 PDF 5–6쪽(인쇄221–222쪽)은 coastdown ABC와 부품 손실 데이터를 함께 사용할 때 일부 회전손실이 중복될 수 있으며, neutral spin-loss 측정으로 ABC의 대응 부분을 조정하는 방법을 설명한다. EPA EDU 자료와 2024-01-2270은 EDU 경계가 인버터·모터·기어 합성이고, hub 실험에는 반축/베어링도 남아 있음을 보여준다.

**이 근거로 현재 모델의 ABC–EDU 경계 겹침은 새 우선 검토 후보다.** 앞선 mechanical_loss_selection 결과에서 Final Drive 효율1/Differential 손실 비활성을 확인한 것은 명시적 컴포넌트 손실의 중복을 점검한 것이며, ABC 내부 수동 회전저항과 합성 EDU 맵의 겹침을 완전히 배제한 것은 아니다. 앞선 결과를 전체 중복 부재로 확대 해석하지 않는다.

기존 Q1 0토크 절점 손실을 해당 실행의 회전수에 따라 적분한 규모는 61905060/61에서 1.373510/0.488251kWh다. 이 값에는 전기·모터·기어 손실이 함께 있어 neutral 기계손실로 식별된 값이 아니다. **이 값 전체나 Target−Set 전체를 빼서 에너지 오차를 줄이는 보정은 하지 않는다.** 현재 맵의 unpowered_torque_loss_Nm는 0으로 저장돼 있어 별도로 사용할 Bolt 수동 회전저항 수치를 제공하지 않는다.

다음 수치 보정에 필요한 것은 호환 Bolt의 neutral/backdrive 회전저항 또는 분리 기어 손실의 속도/온도별 자료다. 2026-01-0198의 공개 초록은 기어 유무를 분리한 후속 시험을 설명한다. 이번 확인에서는 공개 수치표/다운로드 가능한 분리 맵을 확보하지 못했으며 초록만으로 숫자를 만들지 않았다. EPA 공개 맵 목록에는 기존 EDU와 MOTO 패키지가 있으나 MOTO만으로 인버터/기어 손실을 완결할 수 없다.

## 4. CAN 전류·토크의 독립 계측 경계는 아직 확정되지 않는다

원본 Motor_1_current_DMCM1은 A, Motor_1_torque_DMCM1은 Nm, Motor_1_speed_DMCM1은 rpm으로 기록돼 있지만 description/측정 위치/전류의 DC·AC 정의가 비어 있다. phase_u/v/w_current 채널이 별도로 존재한다는 사실도 generic current를 DC로 인증하지 않는다. 이번 공개 검색에서도 이 정확한 채널의 제조사/ANL 정의표를 확보하지 못했다.

2024 EPA 논문은 inverter DC, AC, hub 토크를 별도 장비로 측정하고, hub 토크/속도를 기어비7.05로 변환해 motor-equivalent 축을 만든다. 따라서 현재 합성 EDU 맵의 출력 경계를 실제 rotor CAN torque×speed와 완전히 같다고 볼 수 없다. 기존 CAN VI와 torque×speed 결과는 진단 후보로 유지하고 실측 인버터/EDU 효율이라고 부르지 않는다.

Dyno 속도와 CAN rpm의 지연 적합 없는 운동학 대조에서는 30km/h 초과·|가속도|<0.2m/s²의 반경 진단 중앙값이 0.314071/0.313845m였다. 현재 반경0.3135m와 근접하지만 시간동기·슬립·신호 스케일이 섞인 값이므로 반경을 이 중앙값으로 자동 보정하지 않는다.

## 5. 배터리 보완 근거: 방전/동특성 수치 확보는 여전히 미완료

기존 NREL/TP-5500-75323의 OCV/R는 충전 목적의 단순 모델이며, Hioki 계측과 CAN을 병합한 시험을 설명한다. 기존 확보한 자료의 OCV/R 좌표·용량·짧은 정지 이력 한계와 독립시험 잔차 판정은 유지한다. 이번 검색에서도 호환 2017 Bolt의 제어된 HPPC·평형 OCV·초기 이력 수치 원자료를 추가 확보하지 못했다. 이는 모든 곳에 자료가 없다는 증명이 아니다.

원본의 모터 HV 전압은 61905060에서 약355.5–384.6V, 61905061에서351.8–371.1V이고 현재 EDU 표는 단일400V다. CAN oil 온도는48–68/54–63°C, 계산 motor 온도는67–83/76–80°C다. 이 값은 배터리 온도가 아니다. 단일 전압 표의 일반화와 열상태 차이를 기록하되 전압·온도별 손실 보정계수는 새로 만들지 않았다.

## 현재 행동과 재개점

질량/Target ABC 입력값 일치는 확정했으므로 그 확인을 반복하지 않는다. CAN 정의와 배터리 파라미터의 미확정 경계를 실측 검증 통과로 격상하지 않는다. 최신 우선순위는 **Bolt EDU와 coastdown 경계가 겹치는 기계 회전손실을 분리할 공개 수치 근거 확보**다. 원자료를 더 찾는 대신 임의로 효율/ABC를 맞추거나 현재 제안 목표를 변경하지 않는다. 추가 CRUISE M 실행 요청은 없다.
