# 회생 차단 원인 분리 실행

## 확인된 설정

BMS ECM→Charge Power의 SOC85%와99.5%가 모두0kW다. 제출된 후보 실행의SOC93.142532→88.836355%는전구간이0kW영역이다. 이는배터리충전이거의없는결과와일치한다. SoC C Function은두모듈SOC최소/최대/평균계산이며거기에충전차단값을임의추가하지않는다. Range/Performance/Generator Work도수정하지않는다.
