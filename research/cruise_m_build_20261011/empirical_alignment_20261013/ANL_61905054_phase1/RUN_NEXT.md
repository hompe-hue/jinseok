# ANL 61905054 실측 주행 입력 — 실행 단계

설정 화면 재확인은 중단한다. 기존 BEV 동작과 FTP75 발전 정지 검증은 완료 상태로 유지한다. 현재 Module 1 화면의 48S3P/Maximum charge56Ah/connectionR0/RC비움은 기존 기록과 일치하며, 추가 설정 스크린샷을 요청하지 않는다.

## 현재 입력 형식 — sample.dat 반영 완료

사용자 제공 sample.dat의 7열 헤더와 단위, CRLF를 따른 `ANL_61905054_BoltEV_Phase1.dat`를 사용한다. 이전 2열 CSV/TSV는 변환 원본으로만 보존한다. Time / Velocity / Gear / Shift Time / Start Switch / Min. Velocity / Max. Velocity 순서다. Gear=1, Shift Time=0, Start Switch=1(마지막 0)은 샘플을 따른다. 속도 하한·상한은 목표속도와 동일하게 두었으며 실측 허용오차를 의미하지 않는다. 시간과 속도는 15자리 정밀도로 보존했다. GUI import는 아직 실행하지 않았다.

다음 시작점: 새 ANL 케이스의 주행프로파일 편집창에서 이 DAT를 불러오고, 종료시간 1144.898908초로 실행. 기존 설정 확인은 반복하지 않는다.

## 준비된 파일

- ANL_61905054_Phase1_driver_1s.csv: 시간[s] / 속도[km/h], 1146점, 0–1144.898908 s. 정수초와 실제 마지막 소수초를 포함한다.
- ANL_61905054_Phase1_driver_1s_paste.tsv: 같은 두 열, 헤더 없이 표 붙여넣기용.
- ANL_61905054_Phase1_reference_native.csv: 계측기/CAN 원래 시계를 보존한11450점 기준값. 배터리 전압·전류·순DC전력, SOC 세 좌표, 온도, 보조부하 채널 포함.
- sources/ANL_61905054_selected_native_rows.csv: 이전 공개자료 원본 선택채널CSV. 기존 source_hashes.json과 SHA256 일치 확인.
- phase_preparation.json: 구간 추출/재표본화/거리오차/초기상태/범위와 한계.

기존 battery_data_quality.json의 Phase_1 행 [260,11710)을 그대로 사용하고 계측기 시계를 t=0으로 이동했다. 원본 구간 약0.1s 간격, 17.014852892km; 1s속도 입력17.015158286km. 거리 차이는0.001794869%다. 네이티브 기준값은 보간하거나 자동 CAN/계측기 시계 정렬하지 않았다.

## 다음 실제 작업

1. 기존 FTP75 BEV 케이스를 복사하여 `ANL_61905054_Check` 같은 새 케이스로 보관한다. 현재 기본 모델 수치의 재확인과 수정은 요청하지 않는다.
2. 새 케이스의 주행 프로파일에 driver CSV 두 열을 대응시킨다: time_s → Time[s], speed_kmh → Velocity[km/h]. 표붙여넣기를 지원하는 편집창에서는 TSV 두 열을 사용한다. 정확한 네이티브 .prox 문법을 확인하지 못했으므로 이 CSV를 .prox 파일이라고 표시하거나 단순 확장자 변경하지 않는다. UI가 .prox만 받으면 현재프로파일의 정상 export를 템플릿으로 받아 동일 형식으로 변환하는 작업이 필요하다.
3. 실행 종료시간은1144.898908s, 초기구현 점검의 기존BEV 설정을 유지한다. 이 첫 실행의 완료조건은 실제 입력 추종과 수치 일관성이지 실차 에너지 검증 통과가 아니다.
4. 결과는 새 Report Page/새 케이스 참조로 `velocity_ANL61905054.csv`, `battery_ANL61905054.csv`, `generator_ANL61905054.csv`를 내보낸다. 같은 파일명으로 기존FTP75 원본을 덮어쓰지 않는다.
5. 속도 시계열/거리/추종오차, V/I 적분과 배터리순DC전력, 발전 정지를 비교한다. 초기조건이 맞지 않은 상태의 전압·SOC·에너지 차이는 조건불일치를 포함한 예비 진단으로 표시한다.

## 비교 조건과 해석

ANL61905054는Day4 첫10mile drive이고FTP75가 아니다. 원본Phase표시SOC99.9855→98.025%, HPCM2SOC96.824→93.688%, 시험실23.34°C, 배터리CAN22→22.5°C, HVAC0이다. LV DCDC 출력은약322–494W지만HV보조부하 입력과 같다고 가정하지 않는다. 기존초기SOC60%/등온25°C/보조0.96kW는이원본과일치하지않으므로현재2.172kWh와단순오차비교해서독립검증통과라고쓰지않는다.

초기조건 대응/식별은 실제 속도 실행 결과와 출처를 바탕으로 다음 별도 파일에 고정한다. 표시SOC를모델SOC로복사하거나임의로전압/SOC/Ah를동시보정하지않는다. 실측수치에따른초기조건설정은이미한모델설정의재확인과구분한다.

## 현재 완료 / 재개 위치

현재 파일 준비와 데이터 검산 완료. CRUISE M native profile import/새 케이스 실행은 아직 사용자의 Windows에서 수행되지 않았다. 다음 시작점은 새 실측 주행 프로파일 적용이다. 질량/온도/배터리 설정 확인 단계로 되돌아가지 않는다.
