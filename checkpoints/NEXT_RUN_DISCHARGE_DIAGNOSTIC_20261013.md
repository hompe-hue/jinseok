# 다음 실제 작업: 61905060 방전 제한 단일변수 진단

2026-10-13. 사용자의 목표는 CRUISE M Bolt EV 모델을 공식 공개 실측 자료와 비교하여 신뢰성을 확보하는 것이다. 원인 분리를 위한 진단 실행과 실차 한계 식별/독립 검증은 구분한다.

## 왜 지금 실행하는가

원본 프로젝트의 Discharge Power SOC 특성표는 SOC 40–99.5%에서 45kW다. 원본 ANL61905060 실측 배터리 방전 피크는 64.790214kW다. 기존 실행은 약45kW 평탄 구간59점과, 실측45kW 초과/모델 속도부족1km/h 초과가 겹친19점이 기록됐다. 인과는 아직 미확정이지만 현재 예제 제한이 이 시험의 실측 출력을 허용하지 못한다는 수치 근거가 있다. 호환 HPPC나 분리 기어 손실을 아직 확보하지 못해도 이 한 요인의 영향을 진단할 수 있다.

80kW는 이번 시험의 64.79kW 실측 피크보다 여유를 둔 진단 설정이다. Bolt 실제 BMS 허용전력이나 영구 보정값으로 확정하지 않는다. 결과에 새로운 80kW 포화가 생기는지도 확인한다. 에너지 오차가 반드시 감소한다고 예측하지 않는다.

## 사용자가 할 1회 실행

1. 기존 원본을 보존하고 다른 이름(예: Bolt_ANL61905060_Dis80_Diagnostic.proj)으로 저장한다.
2. 모델의 Discharge Power 블록 SOC–허용 방전전력 특성표에서 45kW 절점 네 곳만 80kW로 바꾼다. SOC 축은 변경하지 않는다.

| SOC % | 기존 kW | 진단 kW |
|---:|---:|---:|
| 0 | 0 | 0 |
| 20 | 0 | 0 |
| 30 | 24 | 24 |
| 40 | 45 | 80 |
| 75 | 45 | 80 |
| 85 | 45 | 80 |
| 99.5 | 45 | 80 |

3. 주행 입력은 ANL61905060_BoltEV_Phase1.dat의 61905060 실제 속도로 지정한다. 케이스 이름만 변경하면 SOC/온도/종료시간까지 바뀌는 것이 아니므로 아래 값과 함께 적용한다.

| 항목 | 고정할 값 |
|---|---|
| Module 1 / Module 2 초기 SOC | 둘 다 81.254247% |
| Module 1 / Module 2 정의 온도 | 둘 다 24.5°C |
| Environment 온도 | 23.287737°C |
| 종료시간 | 3150.896995초 |
| Power Consumer | 0.40kW |
| Charge Power, OCV/R, EDU 손실표, 질량, ABC, 반경 | 기존 61905060 비교 조건 유지 |
| 발전계 | 기존 BEV 비교처럼 정지 |

4. 기존 결과와 같은 Vehicle/Battery/Generator 모니터를 CSV로 내보낸다. velocity_ANL61905060_Dis80.csv, battery_ANL61905060_Dis80.csv, generator_ANL61905060_Dis80.csv처럼 기존 원본과 구분한다. 가능하면 말단 시각을 포함하고, 1초 출력만 있으면 기존과 공통20–3150초에서 우선 비교한다. 임의로 마지막 소수초를 추정하지 않는다.
5. CSV 세 파일을 첨부한다. 다른 맵/부하를 동시에 바꾸거나 추가 케이스를 실행할 필요는 없다.

## 결과를 받으면 이어서 수행할 분석

- 초기조건·프로파일·발전정지·전력경계·시간 범위를 확인한다.
- 기존45kW 실행과 같은 구간에서 속도, 전압, 전류, 순/방전/회생DC 에너지를 비교한다.
- 기존 피크 제한 및 속도 오차 구간이 어떻게 달라졌는지 확인한다. Discharge Power limit/request 모니터가 제공되지 않으면 단일변수 변경·출력 대조의 인과 범위를 제한한다.
- 전체 에너지 변화와 남은 편차를 따로 기록한다. 제한을 풀어도 남는 오차를 임의로 맵/ABC에 적합하지 않는다.
- 현재61905060/61은 진단에 사용한 시험임을 명시한다. 보완 모델을 고정한 뒤 별도 미사용 주행시험으로 최종 독립 확인을 설계한다.

## 검증 로드맵

구현/숫자 대조는 상당 부분 완료됐다. 실제 시험의 질량/Target ABC 대응도 원본 TDMS로 확인됐다. 다음은 이 명확한 제어 불일치의 진단 실행이다. 그 이후 남는 편차에 대해 ABC–EDU의 수동 회전손실 경계와 배터리 동특성을 근거별로 보완한다. 분리손실 자료 부족 때문에 모든 진단 실행을 보류할 필요는 없지만, 근거 없는 수치 보정은 하지 않는다.

기존 RMSE2V/평균편차1V/에너지5%는 연구 제안 목표이며 공식 인증기준이 아니다. 결과를 보고 합격선을 바꾸지 않는다. 검증 범위가 확정된 후 가상 EREV 발전계 및 SOC30/50/70% 비교로 진행한다.
